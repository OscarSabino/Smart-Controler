# Bibliografia

## Librerias de Software

### Arduino
1. Shirriff, K., Khan, R. & Joachimsmeyer, A. (2025). *Arduino-IRremote* (Version 4.7.1) [Libreria de Arduino]. https://github.com/Arduino-IRremote/Arduino-IRremote
   - Recepcion y envio de senales infrarrojas por protocolos NEC, Sony, RC5, RC6, Samsung, LG, JVC.

2. Suat, F. & Scaprile, L. (2025). *rc-switch* [Libreria de Arduino]. https://github.com/sui77/rc-switch
   - Transmision y recepcion de senales RF 433MHz con codificacion OOK.

3. Arduino. (2025). *SoftwareSerial* (Version 1.0) [Libreria incluida en Arduino IDE]. https://www.arduino.cc/en/Reference/softwareSerial
   - Comunicacion serie por pines digitales adicionales (pines 10 y 11 para HC-05).

4. Arduino. (2025). *Arduino Core API* [Entorno de desarrollo]. https://www.arduino.cc/
   - Funciones de entrada/salida, control de tiempo y comunicacion serie nativa.

### Python
5. Python Software Foundation. (2025). *Python* (Version 3.x) [Lenguaje de programacion]. https://www.python.org/
   - Lenguaje principal del servidor de comunicacion.

6. Liechti, C. (2025). *pySerial* (Version 3.5) [Libreria Python]. https://github.com/pyserial/pyserial
   - Comunicacion serie con puertos COM (USB y Bluetooth) desde Python.

7. Python Software Foundation. (2025). *http.server* [Modulo de la libreria estandar]. https://docs.python.org/3/library/http.server.html
   - Servidor HTTP ligero con ThreadingHTTPServer para peticiones concurrentes.

### PHP y Web
8. The PHP Group. (2025). *PHP* (Version 8.x) [Lenguaje de programacion]. https://www.php.net/
   - API REST para gestion de dispositivos, comandos y programaciones.

9. Oracle Corporation. (2025). *MySQL* [Sistema gestor de bases de datos]. https://www.mysql.com/
   - Almacenamiento de configuracion de dispositivos, comandos y horarios.

10. Apache Software Foundation. (2025). *Apache HTTP Server* [Servidor web]. https://httpd.apache.org/
    - Servidor web integrado en XAMPP para servir la interfaz y la API PHP.

11. Mozilla Foundation. (2025). *Fetch API* [Especificacion web]. https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API
    - Comunicacion asincrona desde el navegador hacia la API PHP y el servidor Python.

## Componentes de Hardware

12. Arduino. (2009). *Arduino UNO Rev3* [Microcontrolador ATmega328P]. https://store.arduino.cc/products/arduino-uno-rev3
    - Placa de desarrollo principal del proyecto.

13. Microchip Technology. (2024). *ATmega328P Datasheet* [Microcontrolador de 8 bits]. https://www.microchip.com/en-us/product/ATmega328P
    - Microcontrolador de la placa Arduino UNO.

14. Vishay Semiconductors. (2019). *TSOP38238 - IR Receiver Module* [Receptor IR]. https://www.vishay.com/docs/82491/tsop382.pdf
    - Receptor de infrarrojos con demodulador de 38 kHz, conectado al pin 2.

15. Guangzhou HC Information Technology. (2015). *HC-05 Bluetooth Module* [Modulo Bluetooth]. https://www.arduino.cc/en/uploads/Main/HC05.pdf
    - Modulo Bluetooth clase 2 para comunicacion inalambrica serial.

16. Hope Microelectronics. (2019). *RFM69HCW / RXB6 - 433MHz RF Modules* [Modulos RF 433MHz]. https://www.hoperf.com/modules/rf.html
    - Modulos de transmision y recepcion OOK a 433 MHz.

17. Arduino. (2025). *Arduino IDE* (Version 2.x) [Entorno de desarrollo integrado]. https://www.arduino.cc/en/software
    - IDE utilizado para compilar y subir el firmware al Arduino.

19. Git. (2005). *Git* [Sistema de control de versiones]. https://git-scm.com/

20. GitHub. (2008). *GitHub* [Plataforma de hospedaje de codigo]. https://github.com/
